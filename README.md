# Un sushi ?

This is a simple React app to count the pieces of sushi you can eat at a buffet.

The app has two modes:

* **Simple mode:** each piece counts as the same value, and you can only increment one piece at a time.
* **Detailed mode:** you can choose which type of piece you are eating. We all know that a temaki is bigger than a maki, so we take that into account. At the end, you can see a summary of the pieces you have eaten.
